# Cognifyz Machine Learning Internship

This repository contains four machine learning and data analysis tasks completed as part of the Cognifyz Technologies Machine Learning Internship.

## Projects

### Task 1: Restaurant Rating Prediction
- **Objective:** Predict restaurant aggregate ratings using restaurant-related features.
- **Algorithm:** Random Forest Regressor
- **Evaluation:** Mean Squared Error (MSE) and R-squared (R²).
- **Additional Analysis:** Feature importance visualization.

### Task 2: Restaurant Recommendation System
- **Objective:** Recommend restaurants based on user preferences.
- **Approach:** Content-based filtering.
- **Parameters:** Cuisine, city, and price range.
- **Ranking:** Aggregate rating and number of votes.

### Task 3: Cuisine Classification
- **Objective:** Predict a restaurant's main cuisine using other restaurant attributes.
- **Algorithm:** Random Forest Classifier.
- **Evaluation:** Accuracy and classification report.
- **Additional Analysis:** Class distribution and baseline accuracy comparison.

### Task 4: Location-Based Restaurant Analysis
- **Objective:** Analyze restaurant geographical distribution and location-based trends.
- **Approach:** Exploratory Data Analysis (EDA).
- **Analysis:** City-wise restaurant counts, average ratings, and average costs.
- **Visualization:** Geographical scatter plot and city comparison charts.

Install the dependencies:


pip install -r requirements.txt
